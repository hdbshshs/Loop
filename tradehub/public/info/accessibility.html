Accessibility

We want everyone to be able to use Loop. The site is built with real links, buttons and form labels so it can be used with a keyboard and with assistive tools, and it works on phones and desktops.

We have not had a formal accessibility audit yet, so there will be rough spots. If something on Loop is hard or impossible for you to use, email [SUPPORT EMAIL] with the page and what went wrong, and we will fix it.
